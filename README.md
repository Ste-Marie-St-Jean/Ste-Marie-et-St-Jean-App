# Retraites — Église copte orthodoxe Sainte Marie et Saint Jean

Application des retraites spirituelles de la paroisse : programme, choix des chambres et infos pratiques pour les retraitants ; gestion des inscriptions pour les organisateurs.

Application web installable, hébergée sur GitHub Pages. Les données et les connexions sont gérées par Firebase : aucune donnée personnelle n'est stockée dans ce dépôt.
